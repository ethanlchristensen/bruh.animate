Snow Effect
===========

With ``on_resize="resize"``, snow adapts to the new simulation dimensions.
Floor-connected piles follow the bottom edge; visible airborne flakes retain
position, drift and fall delay. Cropped snow is discarded. Explicit collision
surfaces remain fixed. See :doc:`../resize` for the full adapter contract.
