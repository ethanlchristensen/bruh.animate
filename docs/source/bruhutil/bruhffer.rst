Bruhffer
========

``shift`` and ``shift_line`` rotate rows in terminal cells. Positive amounts move
right, negative amounts move left, and amounts wrap modulo the width. Empty rows
are unchanged. These are wrapping rotations, unlike clipped drawing or scrolling.
