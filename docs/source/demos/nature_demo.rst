Nature Gallery
==============

Run ``python -m bruhanimate.demos.nature_demo`` for six simultaneous panels:
Water, Reaction-diffusion, Smoke, Metaballs, Cloth, and Terrain. q quits.
Resize freely: the layout reallocates each owned panel without resetting it.
The gallery presents at 60 FPS and each panel updates at 30 ticks/sec.
On very small terminals panels clip or hide until more space becomes available.

See :doc:`../natural_effects` for individual demos, typed settings, controls,
and presets. The factory-based layout in this demo is also a composition example.
